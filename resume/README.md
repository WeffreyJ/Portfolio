# Resume Variants

These are the current resume sources in this repo:

- `jeffrey-walker-master-resume.tex`: full source-of-truth version
- `jeffrey-walker-controls-resume.tex`: default public resume for controls, autonomy, and GNC roles
- `jeffrey-walker-robotics-resume.tex`: tailored version for robotics, embedded, and mechatronics roles
- `jeffrey-walker-research-resume.tex`: tailored version for research-heavy and advanced R&D roles
- `jeffrey-walker-master-resume.md`: editable narrative source

Compile any resume PDF with:

```bash
tectonic --outdir public/assets/docs resume/<filename>.tex
```
